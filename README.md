# Skyline Tether

A low-poly first-person momentum traversal prototype built with Three.js, TypeScript, and Vite.

## Current prototype

- Dual left/right energy tethers
- Momentum, gravity, steering, boost, and braking
- Desktop mouse/keyboard controls
- Mobile and tablet touch controls
- Low-poly procedural city course
- Collectibles, score, hazards, collisions, and three levels
- Automatic GitHub Pages deployment

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Controls

### Desktop

- Mouse: look
- Left click: left tether
- Right click: right tether
- W/A/S/D: steer
- Space: boost
- Shift: brake
- R: reset

### Mobile / tablet

- Drag the screen: look
- Left joystick: steer
- L / R buttons: tethers
- Boost and Brake buttons: speed control
